WAYS TO PLAY

YOUNG PILOTS

THE ORBIT RING

Six gentle levels in a glowing electric space world. Ride golden solar breezes, slip through light gates and bounce off pinball bumpers. A bump just says "Bonk! Try again."

MISSIONS

27 LEVELS, 3 STARS EACH

Earn a star for finishing, one for every spark, and one for beating the clock. Seven classic worlds wait after the Orbit Ring, each with a bigger ship.

DAILY RUN

A NEW COURSE EVERY DAY

Everyone gets the same fresh course each day. Random Run builds a brand-new one whenever you want, so there is always somewhere new to fly.

LEVEL EDITOR

BUILD AND SHARE

Paint your own levels tile by tile. The editor checks that your level can be finished, then gives you a short code a friend can paste in to play it.
